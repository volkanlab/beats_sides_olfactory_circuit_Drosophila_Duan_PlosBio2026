# beats_sides_olfactory_circuit_Drosophila_Duan_PlosBio2026

R scripts for the analyses presented in Duan et al. (2026) Deciphering the Combinatorial Expression and Genetic Regulatory Mechanisms of Beats and Sides in the Olfactory Circuits of Drosophila. 

This work is soon to be published in PLOS Biology. The BioRxiv preprint was posted in 2025: https://doi.org/10.1101/2025.05.31.657193
